# Project Guidelines: College Practicals

## Scope & Purpose
All code, designs, and tasks produced in this workspace are for college practical exams and lab submissions.

## Core Rules:
1. **Realistic 1-Hour Student Scope**:
   - Everything produced must look naturally hand-typed by a student in a 1-hour practical lab exam.
   - Do NOT over-engineer solutions with excess boilerplate, dozens of external libraries, complex state management, or enterprise patterns.
   - Keep code concise, clean, and directly aligned with the question requirements.

2. **File & Code Structure**:
   - Keep file count minimal (typically 1-3 files: HTML, CSS, JS or single scripts).
   - Use standard, easily explainable logic that a student can defend in a viva or oral exam.
   - Use straightforward naming and clear comments for key sections.

3. **No Unnecessary Features**:
   - Implement exactly what the practical question asks for.
   - Avoid adding unnecessary toasts, animations, complex fallback layers, or excess helper functions unless explicitly requested.
